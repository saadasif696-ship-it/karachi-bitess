This project brief outlines a 21-day solo capstone project to build Karachi Bites, an online ordering system for a restaurant with three branches. Emulating a real freelance experience, students must create a mobile-first, responsive solution allowing customers to browse a menu, place orders, and track status, while providing an admin dashboard for staff. Using Node/Express and vanilla frontend technology, developers are required to adhere to a specific API contract, manage fixed deadlines, handle client changes, and deliver full documentation. Assessment criteria focus on functionality, security, responsive design, and professional communication.
